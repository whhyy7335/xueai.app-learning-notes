# 2026.8.11 学习笔记

## 大模型原理 基础原理
1.大模型就像一个人类幼崽，需要教他如何坐起来，如何躺下去，如何表达自己肚子饿，自己不舒服等等这些内容，就比如说我教他肚子饿要用手拍一下肚子，他学会了，当他再次肚子饿的时候用手拍肚子我就知道他饿了，等到他再长大一点，学会了讲话，他可以讲给我听他饿了，再大点，他会用手机了，他可以发信息告诉我他饿了，但是呢因为他有很多人要聊天，偶尔也会发错信息给我（大模型的确会「发错信息」，但主要原因不是「聊天的人太多」，而是它本质上只是在玩概率游戏：下一个词选「饿」的概率是 0.85，选「累」的概率是 0.12，它选了概率最高的，但概率高不等于事实对，就像发信息的时候，A问：yes or no  B回答：是的 也有。），等到再往后，他学的东西越来越多了，会发邮件了，核对好所有信息后，发送的邮件准确无误。

2.先看两个词：Temperature和Top-P；Temperature我认为可以翻译为：你有多相信"小概率事件"我简称小T，而Top-P则是：要"靠谱选项"还是"全盘接受"我简称小P，就拿天气预报的例子来看，如果把小T的数值拉的很高，模型连明天会有月球袭击地球都有可能报给你，如果小T接近 0的时候，那时候转盘被焊死，几乎只选第一名。；再来看小P，如果数值很高，则明天月球袭击地球的情况都得考虑，得纳入候选池，而如果很低，则只认概率最高的，近乎偏执的保守；实际情况则是两个参数配合着使用，严谨的问题参数都会很低，需要发散的问题，两个参数都会很高

3.token又如何推着另一个token往前走呢，链条如下：前文 Token → 算概率分布 → 【小T+小P决定怎么选】→ 新 Token → 循环；但循环本身不会变聪明——它只是在不断接话茬，它像工厂流水线一样机械重复，但比流水线多了一层随机性，就像课程中的这句话一样"它没有意图、没有记忆、没有常识判断，只有概率，只有 Token。"在每次循环后，"前文"都会变长。新生成的 Token 立刻成为下一次预测的一部分。这也是为什么对话越长越容易跑偏，它一直在"接自己的话茬"，慢慢就歪了，就像那个小朋友们做成一排在背后写字接力一样，最后的字和最开始的字会变得完全不一样。理论上训练时看过的文本越丰富、质量越高，模型学到的概率分布越贴近现实。

4.从CNN滑动窗口到RNN记忆衰减再到BERT双向注意力，这三代都在解决同一个问题：怎么让模型看到更完整的上下文，但是人们花费大量时间精力解决完这个问题后才发现，它们的目标不是"生成"，而是"理解"；GPT因果生成的与众不同是原因是没有继续在前三代的框架里修修补补，而是从“理解”这个目标换到了“预测下一个词”，这个目标极其的简单，它可以做到无监督训练，只要从互联网上抓海量文本，让模型不断玩"接龙"就行，这种"接龙"训练需要海量文本，数据来源和版权问题因此成了行业争议的热点。
